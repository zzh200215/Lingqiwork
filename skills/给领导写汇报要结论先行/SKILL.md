# 给领导写汇报：结论先行

## 什么时候用它

你要把一段时间的工作结果讲给领导听，而他只给你一分钟。凡是写成「背景 → 过程 → 结论」的，
都算没用对——他会先问结果。

## 按这个顺序写

1. **第一句话就是结论。** 一个判断句，不是「我们调研了 X」。写清：建议做什么 / 结果是什么。
2. **再给 2–3 条支撑。** 每条先给判断，后跟一句依据（数字、事实、来源）。
3. **只写他需要决定的那一件事。** 需要他点头的，放在最后一句，写成一个具体的问题。
4. **删掉过程。** 怎么调研的、试过哪些方案，除非它改变了结论，否则不写。
5. **代价说在前面。** 要资源、要时间、有风险，写在结论那一段里，不要藏。

## 长度

一页纸。超过一页先砍支撑条数，再砍依据。
